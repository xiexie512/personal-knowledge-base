# Mac mini 统一内存选择

> 统一内存（Unified Memory）是 M 芯片 Mac 的 RAM，系统、应用、模型共享。

## 8GB 够不够？

### 场景判断

| 场景 | 8GB 是否够用 |
|---|---|
| 日常办公 + 网页 + 轻量开发 | ✅ 够用 |
| 云端 LLM + Agent 任务（本地不跑模型） | ✅ 够用（峰值约 4.5~6GB） |
| 本地跑 3B 模型 + 开发 | ⚠️ 勉强，需按需加载 |
| 本地跑 7B+ 模型 | ❌ 不够，OOM/swap 严重 |
| 同时多个 Agent 沙箱 | ❌ 容易爆内存 |

## 内存占用拆解（云端模型模式）

- macOS 系统：2.2~3GB
- Harness + WebUI + Cordis：1~1.6GB
- 沙箱插件（含宿主进程）：0.4~0.8GB
- 沙箱内 Agent 脚本：几百 MB
- 合计峰值：4.5~6GB ✅ 8GB 有余量

## 本地模型模式的内存成本

| 模型 | 占用 |
|---|---|
| 1.5B Q4_K_M | ~1GB |
| 3B Q4_K_M | ~2.1GB |
| 4B Q3_K_M | ~2.0GB |
| 7B Q4_K_M | ~4.5GB |

## 选型建议

- 8GB：云端模型 + 轻量开发 + 本地 3B 审查（按需加载）
- 16GB：舒服很多，1~2 个 Agent 并发，跑 7B 量化
- 24GB+：多 Agent 并发 + 本地大模型从容运行

## 关键优化（8GB 机器）

1. 沙箱并发限制为 1
2. 本地审查模型按需加载（或常驻但关闭其他大程序）
3. 避免沙箱内跑大内存任务（大数据集、大数组）
4. 模型文件放 SSD，不要放外接盘
